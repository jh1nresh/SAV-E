# SAV-E App Store screenshots — principles v6

Editable, deterministic App Store campaign exported on 2026-08-22 from
`specs/app-store-screenshot-board-v6.html` using current SAV-E reviewer-demo UI
captures and the owned Memo asset.

## Deliverables

- `iphone-1242x2688/`: five opaque 1242 x 2688 PNGs plus a contact sheet.
- `ipad-13-2064x2752/`: five opaque 2064 x 2752 PNGs plus a contact sheet.

## Conversion direction

- Screen 1 leads with one clear place-memory value proposition.
- Each screenshot carries one primary message.
- Screen 2 sells the result of saving a shared clue and uses an explicitly
  fictional friend-sharing cue instead of a fabricated testimonial.
- Screen 3 builds trust with truthful privacy and confirmation language; no
  rating, review, award, download, or press claim is invented.
- iPhone and iPad use separate native compositions without letterboxing,
  stretching, or whole-image regeneration.

These files use deterministic current app captures, but App Store Connect
upload and release remain human-controlled.
