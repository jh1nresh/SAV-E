# Root Map — Little Atlas prompt

Read `../design.md`. This is an illustrated atlas composition, not a modal map.

Build a 402 × 874 pt iOS Root Map. Keep Memo + SAV-E at top and a compact
`18 Map Stamps` chip. The map fills the page with illustrated streets, water,
small Tokyo landmarks, green saved pins, three coral numbered route stops, and
one dashed route. Keep one cream `Search places or ask SAV-E` drawer above the
fixed Root tabs. Select Koffee Mameya and transform that same drawer into the
compact paper place peek; Memo, place name, Shibuya, confirmed chip, one
sentence, coral Open details action, and a quiet bookmark action remain in the
same three-state collapsed / medium / large surface.

Do not add a second drawer, hide the tabs, expose Review/Friends/Lists inside
Map, add a second detail renderer, or use photoreal map tiles in this
visual-direction prototype.
