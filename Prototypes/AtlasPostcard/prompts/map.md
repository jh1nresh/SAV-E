# Root Map — Little Atlas prompt

Read `../design.md`. This is an illustrated atlas composition, not a modal map.

Build a 402 × 874 pt iOS Root Map. Keep Memo + SAV-E at top and a compact
`18 Map Stamps` chip. The map fills the page with illustrated streets, water,
small Tokyo landmarks, green saved pins, three coral numbered route stops, and
one dashed route. Select Koffee Mameya. Show a single compact paper place card
above the fixed Root tabs; Memo peeks over its edge, and the card contains place
name, Shibuya, confirmed chip, one sentence, coral Open details action, and a
quiet bookmark action.

Do not open a sheet, hide the tabs, add a second detail renderer, or use
photoreal map tiles in this visual-direction prototype.
