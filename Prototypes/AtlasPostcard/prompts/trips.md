# Trips — Little Atlas prompt

Read `../design.md`. This is the root Trips page, not the Trip Plan workspace.

Build a 402 × 874 pt iOS screen. Keep Memo + SAV-E at top and the one global
paste/share-link button. Use a compact `Trips` title and one illustrated atlas
strip. Float a current-or-next Trip postcard over the atlas with timing, dates,
city, stop count, and a clear open affordance. Below it, show at most two
upcoming or planning Trip tickets with distinct sky/lavender state color. End
with one coral `Start a new Trip` action above the fixed Home / Saves / Trips /
Map tab bar.

Do not use a navigation title, ScrollView, generic dashboard intro card,
separate sections for every lifecycle state, or a second bottom navigation.
Opening a Trip must switch to the scoped Plan / Map / Inbox / Share shell.
