# Onboarding envelope shell v6 production composite

## Continuous front mouth

Use case: precise-object-edit

Asset type: production iOS front pocket for the shared onboarding envelope

Inputs:

- `SavesEnvelope`: authoritative owned broad mouth, shoulder, and stitch geometry.
- `OnboardingEnvelopeFront`: authoritative owned blank body, airplane cancellation,
  lower stitch, paper color, and exterior silhouette.

Construct one front-pocket raster. Preserve the upper 90 px mouth geometry and
texture from `SavesEnvelope`, remove the wax-seal region using mirrored clean
kraft texture from the same owned source, then blend into the onboarding body
from y=90 through y=120. Preserve alpha and emit the same 402:207 coordinate
system at 1x, 2x, and 3x.

The result must have one broad continuous mouth and raised shoulders. It must
not contain a detached centre triangle, wax seal, letter, Memo, text, airmail
rail, second pocket, or new runtime overlay.
