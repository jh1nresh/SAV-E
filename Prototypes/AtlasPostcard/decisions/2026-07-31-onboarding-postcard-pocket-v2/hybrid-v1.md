# Hybrid v1

## Preview

`mockups/clue-review-stamp-v1.png`

This is a direction mockup, not implemented UI. Generated text, map fragments,
and illustrations are fixtures; production uses live SwiftUI text and owned
repo assets.

## Screen Mapping

- Clue: coral editable source ticket entering the kraft pocket.
- Review: retained coral receipt behind a sky candidate ticket.
- Map Stamp: mint lifted saved postcard emerging from the same pocket.

## Unified Shell

- Same SAV-E header, step seal, progress rail, title anchor, pocket stage, and
  bottom CTA on all three screens.
- One cream canvas, one atlas type route, one semantic palette, one scalloped
  ticket system, and one coral action color.

## Product State Model

- Coral: incomplete Source Clue; source retained; no place truth yet.
- Sky: Review Candidate; likely match; user decision required.
- Mint: confirmed private Map Stamp; user authored truth.

## Feedback and Expressive Mechanism Rules

- Memo appears once as the pocket guide and moves only to explain the current
  state.
- Normal motion carries one ticket into, forward from, and upward out of the
  pocket. Reduced Motion renders each final state without removing meaning.
- The source receipt remains visible through Review and Map Stamp.

## Generated-Fixture Caveats

- The mockup's cafe photo and atlas crop are directional placeholders.
- Exact copy, iconography, progress labels, and metadata will be natively
  typeset and localized.
- The generated pose inside the concept mockup is not a production asset.
  Production uses separately generated, locally owned Memo pose assets with
  prompt and transform provenance recorded in the asset manifest.

## Remaining Risks

- The Clue editor must remain keyboard-safe without shrinking below a useful
  writing area.
- Dynamic Type and Traditional Chinese copy may require shorter approved copy.
- The production envelope asset may need masking/cropping to support the fixed
  stage without introducing a full-screen raster.
