# 全台街區圖資

此資料集涵蓋台北市以外的 21 個縣市。地圖在縮放層級 16 載入畫面附近的街巷，17 顯示有來源的建物，18 起顯示近景立面。台北市沿用市府實測圖資。

地圖收錄 676,004 個公開地面道路 OSM way，其中 240,385 段帶路名。相連的多個 way 可以屬於同一條街。共有 521,303 個建物輪廓。61,128 個公開具名商業地點之中，有 18,957 個位於建物內且接近外牆。其他店家沿用原有地點圖釘。

## 資料界線

- 公開地面街道包含幹道、住宅路、巷道及步行路徑。私有或禁止通行的道路、隧道、高架道路與停車場內車道會略過。缺少路名的線保留幾何。
- 店面配對限於公開店家座標落在實際建物內，距離外緣約 8 公尺內。門面、招牌顏色與朝向屬插畫示意。建物保留中庭，優先使用高度或樓層標記，缺漏時按建物類型推估。
- 此快照有 420 個輪廓在約一公尺精度下失去有效拓撲，已略過。
- 澎湖、金門、馬祖均有公開街巷與建物。東沙與太平島此次補充快照只有自然景觀資料，未收錄地面道路或建物。
- 分成 3,463 份，gzip 合計 31,608,113 bytes，最大一份 208,728 bytes。2,336 份的整個範圍已驗證位於同一非台北縣市內，其餘在顯示時核對行政界。

## 來源及重建

- 道路、建物、店家依 2026-11-23 公開快照，© OpenStreetMap contributors，ODbL 1.0。[Geofabrik Taiwan](https://download.geofabrik.de/asia/taiwan/taiwan-261123.osm.pbf)
- 行政範圍採用本專案所附國土測繪中心鄉鎮市區界。[內政資料開放平臺](https://data.gov.tw/dataset/7441)
- 離島補片的原始 URL 和 SHA-256 保存在同目錄的 index.json，原始檔在 taiwan/scenery/sources。

使用 Python、pyosmium 與 Shapely 2，從原型根目錄執行下列命令。

```sh
python tools/build-taiwan-streets.py /path/to/taiwan-261123.osm.pbf
```
