# 打狗英國領事館官邸

以 OSM way 205060859 的 L 形輪廓定位山上官邸。磚拱、女兒牆、瓦面和門梯依照片建模，屋頂高度與各開口尺度採比例估測。

230 m 方形場景。OSM 原始擷取時間為 `2026-11-23T18:23:33.433018+00:00`。從原型根目錄執行 `python3 -B tools/city_workflow.py build kaohsiung --skill-dir "$POCKET_CITY_SKILL"`，可重建 HTML 與主地圖網格。
