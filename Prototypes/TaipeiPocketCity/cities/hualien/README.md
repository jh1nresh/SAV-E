# 松園別館

附建物使用原 OSM way 712411693 及其分件。主館長翼對應 way 1350032556。二樓欄杆、灰瓦、拱形迴廊和藤蔓依現地照片，開口尺度為比例估測。`refine-scene.py` 從示意樹群留出館前草地。

180 m 方形場景。OSM 原始擷取時間為 `2026-11-23T18:23:35.690481+00:00`。從原型根目錄執行 `python3 -B tools/city_workflow.py build hualien --skill-dir "$POCKET_CITY_SKILL"`，可重建 HTML 與主地圖網格。 若重做 `scene.json`，再執行 `python3 -B cities/hualien/refine-scene.py`。
